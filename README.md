Get on Board (getonbrd.com) is the leading tech-recruitment platform and applicant tracking system (ATS) for Latin America, connecting companies with a talent database of 1M+ technology professionals. Companies post jobs, run structured hiring processes, and access candidate profiles. Get on Board publishes a public REST API (v0) with an OpenAPI 3.0 specification, a sandbox environment, outbound webhooks, and a first-party Ruby client library. The public API exposes job categories, company profiles, published jobs, and a job search endpoint with no authentication; a private Companies API (API-key authenticated, subscription-gated) covers jobs, applications, hiring processes, professionals, company shells, and webhook management. Surfaced as a portfolio company of 500 Global and enriched by the API Evangelist pipeline.

**Areas:** Company · Recruiting · Job · Hiring · Applicant Tracking · Talent · Developers · Latin America

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Get On Board: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
